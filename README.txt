 Realise par karine et raphael
 Projet d'application météo ( Ecosystème Python)

    pip install -r requirements.txt
    python main.py

Fonctionnalités : météo du jour, prévisions sur 7 jours (graphique Matplotlib),
navigation de 7 jours en 7 jours, fond d'écran jour/nuit, icônes de nuit,
choix de la ville via un menu déroulant, icône météo pour chaque jour.
